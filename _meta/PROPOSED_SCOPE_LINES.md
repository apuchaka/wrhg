# Step 27 — proposed `NOT checked:` lines

**Generated 2026-08-30. Proposals only — no box was edited.**

> [!danger] **A wrong scope line is worse than a missing one.** It converts an unknown into a
> false assurance: a reader seeing `NOT checked: nil` stops looking. Every line below is a
> **draft for a human to complete**, not a line to paste. The `— DRAFT —` marker must be
> replaced with the real scope before any of this reaches a file.

## What was examined

All callouts in all 240 corpus files. **290 boxes assert a check** against a named source
(`verified`, `localised`, `checked against`, `confirmed against`, `cross-verified`).
**Not one carries a `NOT checked:` line** — the retrofit has never been started.

48 further callouts matched the verb but were **excluded** as not verification claims:
`Gap-filled from CSV…`, `Why this file exists`, `Sourcing limitation applying to this whole
file`, `Standalone build, not yet integrated`, `Build status`, `Scope error`. Those record
provenance or build state, not a check against a source.

> [!warning] **Residual false-positive rate in P1 is roughly 20%, by sample.** Some entries
> are warnings or corrections rather than verification claims — e.g. *"This entry treats
> hypoglycaemia without ever defining it"*, *"The classic triad… is present in only…"*.
> Those are marked **`[?]`** below. **Read the box before drafting from it.**
